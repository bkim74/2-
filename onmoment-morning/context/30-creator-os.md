# OnMoment YouTube Creator OS — 정본 브리프 요약

## 핵심 원칙
- 나는 유튜브를 하기 위해 온순간을 사는 것이 아니다. 실제로 온순간을 살고, 그 삶의 몇 장면을 카메라가 목격하게 한다.
- Live fully. Capture lightly. Reflect honestly.
- 매일 콘텐츠를 만들지 않는다. 매일 온순간을 살고 증거만 남긴다. (매일은 삶을 수집하고, 매주는 이야기를 완성한다.)
- AI는 정리·편집하지만 의미와 선택은 김범이 결정한다. Mechanical truth는 자동화, Meaning은 인간에게.
- 시청자는 재미있는 삶의 이야기를 보러 왔다가 자기 삶의 한 장면을 가지고 돌아간다.

## 포지셔닝 / 캐릭터
- 세상을 여행하고, 일상에서 검증한다. 여행은 질문을 열고, 일상은 답을 검증한다.
- 김범 = Observer + Questioner + Storydoer. 현자·인생 선생·고텐션 예능 X.
- 얼굴 비노출 Ego-less POV 채널: Voice + Question + Choice로 존재. 손·발·길·사물·사람의 뒷모습·작업.
- 신뢰 5요소: 실제 목소리 / 실제 여행·일상 / 실제 질문 / 실제 선택 / 실제 후속 결과.

## 공식과 구조
- Human × Question × Choice × Time. 한 여행, 한 사람, 한 질문, 한 선택, 그리고 그 뒤.
- Backend(Reality→Beyond-self→Small Choice→Lived→Return) / Frontend(Question→Journey→Encounter→Choice→What happened?).
- Curiosity → Story → Human → Self-reflection → Choice. (Philosophy → Explanation → Advice 금지)
- Long-form 8단계: Cold Open(0~20초) → Question → Journey → Human Encounter → Tension/POV Shift → Small Choice → Lived Evidence → Return/Open Loop.
- Short = Moment / Long = Story / Return = Trust.

## 시리즈 우선순위
1. 이 사람은 왜 이렇게 살까? 2. 오늘 한번 살아봤습니다. 3. 그 뒤 어떻게 됐을까? 4. 나는 왜 또 이럴까? 5. 여행이 내게 물었다.

## 매일의 촬영 구조
- 아침 2분: 오늘 내 Reality는? / 오늘 어떤 장면을 살아보고 싶은가? / 오늘 조금 궁금한 것은?
- 낮: Moment가 걸릴 때만. 5-shot: WHERE · MOVE · DETAIL · HUMAN · EVIDENCE.
- 경험 후 10~30분 뒤 30~60초 Voice Memo: 방금 무슨 일? / 예상과 무엇이 달랐나? / 내게 뭐가 걸렸나?
- 밤 3분: 가장 기억나는 장면 / 생각이 달라진 것 / 내일 해볼 작은 것 하나.
- Return: D+3 / D+7 / D+30. 실패도 콘텐츠("7일 중 2일밖에 못했습니다").

## 촬영 헌법
Experience First · No Re-enactment · No Manufactured Wisdom · No Forced Choice · Return Honestly.
보여주지 않은 것은 해석하지 않는다. Meaning은 주장보다 고백에 가깝게.

## 장비
Osmo Pocket 4P(20mm Context / 60mm Human·Detail), DJI Mic 3 2TX(TX1 김범, TX2 상대, 32-bit float 백업), Battery Handle, Mini Tripod. 드론·360·조명 등은 데이터로 필요가 확인된 후.

## 90일 Pilot
- Phase 0 (1주): 채널 promise, 타깃, 촬영 헌법, 5-shot, 파일 규칙, AI agent prompt, 편집 template, 동의 기준.
- Phase 1 (4주): 비공개 4편 (일상 2, 국내 하루여행 2). 검증 질문: "이 방식으로 내가 지치지 않는가?"
- Phase 2 (8주): 공개 Pilot — Field/Journey 4 + Return 4 + Shorts 12~16.
- Phase 3: 90일 리뷰 (Audience 돌아오는가 / Creator 더 온순간을 사는가 / Product 시청자 Choice·Return 발생?).
- 발행: Week A Field/Human 12~18분, Week B Return 6~10분. 한 달 Long 4 + Shorts 4~8.
- KPI: 구독자보다 Returning Viewers. YouTube Score와 OnMoment Integrity Score 둘 다 통과해야 게시.
