# 모두의창업 (경기콘텐츠진흥원) — v2 최종본 핵심과 일정 게이트

## 한 문장 피치
전환기 유저가 '현재·바람·선택' 3줄을 실천하면 AI가 가능성을 비추는 자기코칭 커뮤니티.
교육 후 삶의 변화 측정이 필요한 기관이 운영료를 지불하는 B2B2C 솔루션 '온순간'.

## 고객
- 엔드유저(무료): 부모교육·은퇴교육·리트릿 참여자 (전환기). 시니어는 은퇴교육에서 먼저 만날 핵심 세그먼트.
- 구매고객: 생애전환 프로그램 운영기관. 페인: 교육 후 실천·관계가 끊기고 만족도 외 변화 확인 불가.
- 핵심 데이터 단위: 유저가 확인한 'A-B-Bridge 3줄 카드' (개인엔 자기코칭 근거, 밖에선 콘텐츠, 선물의 원본, 기관엔 변화의 근거).

## 3단계 게이트 (통과 기준이 있는 일정)
1. [1단계] 개인 효능 검증 — 1R 50명 코호트.
   - 완료기준: ① 새로운 선택 ② 실제 Storydoing 연결 ③ 재방문 경험 지속. Insight 도달률 20% 우선 검증.
   - 기준 미달 시 유료화 연기. 자금: 고객검증 40% · UX/외주 디자인 30% · 콘텐츠 30%.
2. [2단계] 기관 유료 파일럿 — 초기 설정비 + 기수 이용료(4~12주, 참여자당 2.5만~5만원, 최소 30명) + 운영 지원비.
   - 후보 기관 3곳 협의 (꿈의학교, 경기 재도전학교, 하나파워온 세컨드라이프 네트워크 등).
   - 완료기준: 유료 파일럿 1건, 기수 패키지 확정. 측정: 계약단가, 담당자 운영시간, 재운영 의사.
3. [3단계] 라이프 기프트 이코노미 — 카드·스토리북·리추얼 킷 주문형 (기록자·결제자·수령자 분리).

## 수익성
- 기관당 연 1,200만원, 공헌이익률 60%, 월 고정비 1,200만원 가정 → 약 20곳 손익분기.
- 1년차 3곳 검증 → 2년차 재계약 → 3년차 기관·선물·콘텐츠 복수 매출.

## 협약기간 내 해야 할 것 (책임멘토링 요청 7가지)
1. IP 전략: 변리사와 선행기술 조사, IP Map(특허/영업비밀/저작권), 우선출원 시점. **공개·실증이 신규성에 영향 → 공개 전 출원 판단 필요.**
2. 법인 설립: 개인 명의 상표·저작권·특허 이전/라이선스, 지분, 외주 IP 귀속, 약관·개인정보처리방침·AI 처리 고지.
3. 개인정보와 기관 리포트 경계 검증 (동의 범위 집계 지표만 제공).
4. 소셜벤처 판별 시점 (법인 설립 직후 vs 파일럿 실측 이후).
5. 외주(RFP→견적→검수→IP 귀속→유지보수)와 기관 파일럿(화이트라벨 계약·동의·집계 리포트).
6. 후속지원·투자 로드맵: 특허·법인화 → 효능 검증 → 유료 파일럿 1건 → 반복 계약매출 → 공공실증 → R&D·임팩트투자.
7. Global-ready 최소 원칙 (다국어, 동의·삭제·이동, AI 처리 고지, 해외 결제).

## 보유 자산

- 멘토님 시간은 "결정 직전에만" — 선택지·근거·리스크를 정리해 가져간다.
